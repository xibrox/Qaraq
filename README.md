## What it is

Qaraq is a native-feeling front end for your [AniList](https://anilist.co) account. Sign in once
and your lists, activity, notifications, favourites and stats are all there, with AniList as the
single source of truth.

> [!NOTE]
> Qaraq is not affiliated with AniList.

  <a href="https://altdirect.app/?url=https://raw.githubusercontent.com/xibrox/Qaraq/main/apps.json"><img src="https://altdirect.app/assets/png/AltSource_Blue.png" width="200" alt="Add the source" /></a>

- **iPhone**: tap **Add the source** to open it in AltStore, SideStore, Feather, LiveContainer or
  another sideloading app, which then installs Qaraq and keeps it updated. Or download the IPA and
  sideload it yourself. The source URL is
  `https://raw.githubusercontent.com/xibrox/Qaraq/main/apps.json`.
- **Android**: download `Qaraq.apk` from the [latest release](https://github.com/xibrox/Qaraq/releases/latest).

Every push to `main` rebuilds both into the `latest` release.

## Features

### Lists
- Watching, Rewatching, Completed, Paused, Planning and Dropped, plus your custom lists
- Swipe gestures to bump progress or open the editor, configurable in Settings
- Full entry editing: status, progress, score, dates, repeats, notes and custom lists

### Explore
- Search and filter anime and manga
- Media pages with characters, staff, studios, recommendations and reviews

### Social
- Activity feeds with likes and replies
- Profiles, follows, favourites and stats
- AniList notifications, plus local reminders when episodes you're watching air

### On every screen
- Light and dark themes with accent colours
- Liquid Glass on iOS 26

## Build from source

Requires [bun](https://bun.sh). iOS builds need macOS with Xcode; Android builds need JDK 17 and
the Android SDK. The `ios/` and `android/` folders are generated by Expo prebuild, so don't edit
them by hand.

```bash
git clone https://github.com/xibrox/Qaraq.git
cd Qaraq
bun install
bunx expo run:ios      # or bunx expo run:android
```

Or use the release scripts directly:

```bash
./scripts/build-ipa.sh  # unsigned IPA in build/
./scripts/build-apk.sh  # APK in build/
```

Before opening a PR, run:

```bash
bunx tsc --noEmit
bunx expo lint
bun test
```
